# 🏦 Bank Management System

A Java-based **Bank Management System** developed using **Java Swing, JDBC, and MySQL**. The application simulates core banking operations through a user-friendly graphical interface.

---

## 📌 Overview

The Bank Management System is a desktop application that enables users to perform essential banking operations such as account registration, secure login, money deposit, withdrawal, balance enquiry, PIN change, and mini statement generation. The project demonstrates the integration of Java Swing for the user interface, JDBC for database connectivity, and MySQL for data storage.

---

## ✨ Features

- User Registration (Signup)
- Secure Login Authentication
- Deposit Money
- Withdraw Money
- Fast Cash
- Balance Enquiry
- PIN Change
- Mini Statement

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Muskan2330/Bank-Management-System.git
   ```

2. Open the project in **IntelliJ IDEA**.

3. Configure the MySQL database and update the database credentials in `Conn.java`.

4. Add the MySQL JDBC Connector to the project.

5. Run `Login.java` to start the application.
